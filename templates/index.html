💜 О проекте

«КиноКомедия» — информационная система, разработанная в рамках курсовой работы по дисциплине «Проектирование базы знаний».

Система позволяет просматривать каталог комедийных фильмов, выполнять поиск и исследовать связи между фильмами, актёрами, режиссёрами и жанрами с помощью интерактивной карты знаний.

Для хранения информации используется Microsoft SQL Server, серверная часть реализована на Python и Flask, а визуализация связей — с помощью Cytoscape.js.
