# КиноКомедия

Курсовой проект по дисциплине «Базы знаний».

**Тема:** «Проектирование базы знаний по фильмам в жанре комедия».

## Описание проекта

«КиноКомедия» — веб-приложение для хранения и просмотра информации о комедийных фильмах, визуализации связей между фильмами, жанрами и участниками кинопроизводства, а также формирования рекомендаций похожих фильмов.

## Используемые технологии

- Python, Flask — серверная часть приложения.
- Microsoft SQL Server — хранение данных.
- pyodbc — подключение к базе данных.
- HTML, CSS, JavaScript — пользовательский интерфейс.
- Cytoscape.js — интерактивная визуализация карты знаний.

## Возможности приложения

- Просмотр каталога комедийных фильмов.
- Поиск фильмов по названию.
- Просмотр интерактивной карты знаний.
- Отображение информации о фильмах и их связях.
- Получение рекомендаций похожих фильмов.

## Запуск проекта

1. Установить Python, Microsoft SQL Server Express и ODBC Driver 18 for SQL Server.
2. Создать базу данных `KinoKomediya` и заполнить её данными с помощью SQL-скриптов проекта.
3. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. При необходимости изменить параметры подключения к SQL Server в функции `get_connection()` файла `app.py`.
5. Запустить приложение:

   ```bash
   python app.py
   ```

6. Открыть в браузере:

   `http://127.0.0.1:5000`

Интерактивная карта знаний доступна по адресу:

`http://127.0.0.1:5000/graph`

## Структура проекта

- `app.py` — серверная часть приложения и API.
- `templates/index.html` — главная страница и каталог фильмов.
- `templates/graph.html` — интерактивная карта знаний.
- `static/style.css` — стили пользовательского интерфейса.
- `requirements.txt` — зависимости Python.
- `genres_connections.sql` — SQL-скрипт проекта.
